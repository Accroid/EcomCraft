# SwarmUI 视频模型类型支持

> **语言：** [English 原文](Video%20Model%20Support.md) · 简体中文

本页是视频模型支持目录的中文导读，不是英文原文的完整翻译。完整型号表、演示、下载来源和逐型号参数请查看[英文原文](Video%20Model%20Support.md)及各模型的原始页面；相关信息会随上游更新。

视频模型可支持文生视频、图生视频或音视频组合等不同流程。具体模型能力和推荐参数因模型而异。

视频生成通常需要更多显存、内存、磁盘空间和更长执行时间。开始前确认模型类型、依赖节点、帧数、尺寸、帧率及输出编码器均匹配。缺少节点或编码器时，应检查 ComfyUI 后端日志，避免重复提交仍在执行的任务。

EcomCraft 工作台仅显示管理员发布且被识别为视频的本机 ComfyUI 工作流。复杂节点图应先在原生工作流编辑器中验证，再发布给客户机使用。
