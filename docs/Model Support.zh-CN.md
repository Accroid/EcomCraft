# SwarmUI 模型类型支持

> **语言：** [English 原文](Model%20Support.md) · 简体中文

本页是常见图像模型支持目录的中文导读，不是英文原文的完整翻译。完整型号表、模型演示、下载来源和逐型号配置请查看[英文原文](Model%20Support.md)。

SwarmUI 支持多种图像模型架构。具体模型能否使用，取决于当前 SwarmUI/ComfyUI 版本、模型文件、后端节点和账号权限；英文目录中的历史质量评价也不代表运行保证。

安装模型后刷新模型列表，并确认文件放在匹配的模型目录。遇到加载错误时，检查后端日志、模型文件完整性、模型架构兼容性、所需文本编码器与 VAE，以及自定义节点依赖。老旧或较少见的图像模型另见[少见模型支持中文导读](Obscure%20Model%20Support.zh-CN.md)及其[英文目录](Obscure%20Model%20Support.md)。

模型下载与商业使用许可由模型作者决定。部署前请阅读原始模型页面及其许可，不要将模型文件提交到本项目。
