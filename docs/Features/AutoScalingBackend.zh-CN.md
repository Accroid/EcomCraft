# 自动扩缩容后端

> **语言：** [English 原文](AutoScalingBackend.md) · 简体中文

**此功能仍在开发中，面向熟悉集群调度的高级管理员，不适合普通桌面安装。** 自动扩缩容后端可通过启动脚本在 Slurm、Kubernetes 等算力平台创建 SwarmUI 工作节点。

通常需要一个主 SwarmUI 实例和隔离的工作节点。工作节点应使用独立数据目录、共享且一致的模型文件，并配置控制超时，避免主节点失联后留下持续计费的任务。脚本通过标准输出报告新节点 URL 或失败原因，协议格式与样例以[英文原文](AutoScalingBackend.md)为准。

该功能涉及公网隔离、凭据和 GPU 资源成本，部署前必须在受控环境验证，并设置防火墙、资源上限和故障回收策略。
