# SwarmUI 自动补全

> **语言：** [English 原文](Autocompletions.md) · 简体中文

在提示词框输入 `<` 可查看提示词语法建议；继续输入可筛选，按 Tab 或点击建议即可插入。部分语法建议会展开为可填写的配置说明。更多语法见[高级提示词语法](Prompt%20Syntax.zh-CN.md)。

自定义词表可放在 `Data/Autocompletions`。支持每行一个词条的 `.txt`，也支持首列是词条的 `.csv`。进入 `User → User Settings`，在 `AutoCompletionsSource` 中选择词表，然后返回生成页使用。词表来源和格式示例请查看英文原文。
