# SwarmUI 预设

> **语言：** [English 原文](Presets.md) · 简体中文

预设用于保存一组生成参数，便于重复套用。预设可以从底部的 Presets 标签管理，也可以在提示词或参数中按界面支持的方式应用。

导入官方 SDXL 预设包：从 [SwarmUI 0.6.5 发布页](https://github.com/mcmonkeyprojects/SwarmUI/releases/download/0.6.5-Beta/SDXL.Official.Presets.json) 获取 JSON 文件，打开 SwarmUI 底部的 Presets 标签，选择 Import Presets，导入文件并应用需要的预设。

预设参数可能覆盖当前设置；首次使用或结果异常时请检查实际提交参数。预设包是历史资源，使用前应确认其与当前模型和版本兼容。
