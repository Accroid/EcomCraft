# SwarmUI 扩展使用指南

> **语言：** [English 原文](Extensions.md) · 简体中文

SwarmUI 支持通过扩展增加功能。可在界面中的 **Extensions** 标签页查看当前可用的扩展。

## 查找与安装扩展

1. 启动 SwarmUI。
2. 进入 `Server → Extensions`。
3. 选择感兴趣的扩展，先阅读它的 README，确认功能、依赖与数据处理方式符合预期。
4. 点击 **Install** 安装。

扩展可能来自第三方开发者。安装前请检查其维护状态、权限要求、网络连接行为和所需依赖。

更多讨论可查看 [SwarmUI Discord](https://discord.gg/q2y38cqjNw) 中的 Extensions 频道。
