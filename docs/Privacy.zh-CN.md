# SwarmUI 隐私说明

> **语言：** [English 原文](Privacy.md) · 简体中文

SwarmUI 是可在本地运行的自由开源软件。默认本地生成时，提示词和生成图片不会因为 SwarmUI 自身功能而自动发送到远程服务器。不过，具体数据流仍取决于后端、扩展、自定义节点、网络暴露方式和用户主动配置的服务。

## 有利于隐私的设计

- SwarmUI 核心默认不会自动“回连”中央服务器，也没有内置的数据追踪流程。
- 项目会设置若干环境变量，要求部分依赖关闭遥测，例如用于 Hugging Face 和 Ultralytics 的相关变量。
- SwarmUI 没有必须联系的专属中央服务器。安装、更新等操作可能访问 GitHub、PyPI、NuGet 等公共服务。
- 在本地运行且使用本地后端时，提示词和生成结果通常只在本机处理。
- 主要后端 ComfyUI 也公开表达过重视本地运行与隐私的立场。

## 需要注意的事项

- **安装和更新会联网。** 从 GitHub、PyPI、NuGet 下载程序或依赖时，网络服务提供商可能记录连接信息。
- **后端可能自动更新。** SwarmUI 通常会尝试更新 ComfyUI 和自定义节点，这可能执行对 GitHub 的 `git pull`。如需关闭，可编辑 `Server → Backends` 中的后端并停用 `AutoUpdate`。
- **SwarmUI 本身默认不自动更新。** 用户手动更新或主动开启自动更新后，仍会访问相关上游服务。
- **不能保证所有依赖都绝不联网。** 第三方依赖、扩展或自定义节点可能具有自己的网络行为；发现可疑行为时，应向项目反馈。
- **远程服务器与代理有各自的隐私边界。** 在远程服务器运行时，服务器提供商可能接触数据；使用 Cloudflare Tunnel 等代理时，中间服务可能有能力检查流经其基础设施的数据。
- **公网访问会暴露可访问数据。** 任何成功获得访问权限的远程用户，都可能读取当前 SwarmUI 实例允许访问的内容。
- **扩展和自定义节点可能发起网络连接。** SwarmUI 对官方扩展有减少不必要网络请求的要求，但并不意味着每个第三方组件都受到同样约束。

## 实用建议

1. 只安装来自可信开发者的扩展和自定义节点。
2. 对公网或多人共享实例启用合适的认证，并限制防火墙和反向代理的开放范围。
3. 使用云端模型、提示词优化 API 或远程后端前，确认发送的数据类型、服务商和保留政策。
4. 将重要的配置、模型和输出定期备份。
