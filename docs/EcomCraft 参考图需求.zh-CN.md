## 1. 背景与用户故事

运营手里除了自己的商品原图，常常还有**竞品的成品图**：构图、场景、光线、道具搭配值得借鉴。他们希望“我的商品也出一张这种感觉的图”，而不是自己用文字描述构图——运营说不清“45 度俯拍、左上留白、暖色晨光”这种术语。

用户故事：*“我上传我的商品图和几张参考图（比如竞品的主图、场景图、细节图各一张），平台帮我一张参考出一张图——每张都贴合对应参考的感觉，但商品是我自己的。”* 后续规划：拿竞品的一整套图当参考，直接生成自己的整套图。

## 2. 已确认的决策

以下决策 2026-10-28 与用户确认（A11，见架构文档）：

| # | 决策 |
|---|---|
| 1 | **两条路径都开放**：路径一“借鉴构图”（提示词参考）与路径二“画面参考”（图生图）都提供给用户；路径二需要管理员在执行服务器上**另外安装图生图模型**（依赖 N10 方案），未安装时该选项置灰并说明原因，不影响路径一。 |
| 2 | **只还原感觉，不做一比一复刻**：国内平台普遍允许商品图相互借鉴，海外平台对图片相似度审核更严格。产品设计目标是“还原构图、光线和氛围”，界面文案、提示词组合和（路径二的）重绘幅度都朝这个目标设计；不做“复刻 / 同款 / 一比一”类功能。 |
| 3 | **多张参考图一对一各自生成，不合并**（用户 2026-10-28 澄清）：每张参考图对应一次独立生成任务，产出一张贴合**该参考**的效果图；没有主辅之分、不做多张合并描述。参考图是套图的另一种展开轴（“每张参考一张”与“每种图片类型一张”平行），与 F25 分镜互斥。上限 8 张（与分镜一致），总张数仍受 20 张上限约束。 |
| 4 | **参考图临时使用，不落盘**（代理补充）：参考图只存在于本次请求和内存中的批次里，任务结束即弃；不进商品库、不进 F04 项目归档、不进诊断包和备份（见第 7 节）。 |
| 5 | **模板范围**（代理补充）：路径一是提示词文字，对所有模板可用；路径二需要模板声明 `reference` 图片槽位，初版只给场景类模板（`scene_main` / `detail` / `model` 槽位类型）声明，白底主图不需要。 |

## 3. 两条路径

### 3.1 路径一：借鉴构图（提示词参考）

每张参考图交给视觉模型（MagicPrompt 的 vision 能力，决策 A5 默认关闭，由管理员开启或改用本地视觉模型），产出**该参考自己的**英文构图描述（镜头、光线、场景、色调），追加到对应任务的提示词里，走现有文生图 + 商品保真出图。

- 每张参考一个任务、一段描述，**互不合并、互不干扰**——不存在“多张打架”的问题。
- 不需要新的生成模型，现有文生图链路直接可用。
- 效果：能借到构图和氛围的大方向，细节还原有限——这与“只还原感觉”的定位一致。
- 视觉能力未开启时：界面上传入口仍可用，但显示“借鉴构图需要管理员开启看图描述”，此时参考图对出图无作用（不阻断出图）。

### 3.2 路径二：画面参考（图生图）

参考图作为图生图 / 图像编辑工作流的输入，“把我的商品放进类似这个感觉的画面里”。

- **每个任务的参考就是它自己的输入**：一对一模型下图生图的“单输入”天然成立，无需多图混合（IPAdapter 多图风格混合留待以后评估）。
- **依赖 N10（图生图方案）**：N01 选定的默认模型目前只用于文生图；执行服务器需另外安装图生图模型（如 Qwen-Image-Edit 类指令编辑模型），模板 `requirements` 照常声明，F08 模型清单和依赖检查负责展示缺什么，缺模型时相关模板对用户隐藏（现有机制）。
- 工作流来源：N02 专家制作，或 F57 标准工作流生成器扩展图生图分支（均在 N10 之后）。
- **还原感觉而非复刻**：工作流的去噪幅度 / 参考权重由模板固化在合理区间（偏低），模板审核时把关；界面对路径二的描述统一为“画面参考（还原感觉）”。
- 模板声明 `reference` 槽位（类似品牌资料包 F12 的 `reference_image`）：`"reference": { "image": "参数ID" }`，指向工作流快照里的图片参数；与 `brand_kit.reference_image` 不能指向同一个参数（模板校验报错）。客户端只提交图片数据，服务端按任务填参，白名单边界不变。

## 4. 界面与交互（简易模式）

1. **参考图（可选）入口**：第 2 步新增上传入口，**最多 8 张**，缩略图排布可换行；第 9 张不接收并提示上限。上传时客户端压缩（与画廊选图 F52 相同的 5 MB 上限），服务端按普通图片校验。每张可删除，无主辅标识。
2. **参考方式**：上传后显示两个选项，对全部参考图统一生效——
   - **借鉴构图**（默认）：每个任务由视觉模型读自己的参考图、把构图描述并入该任务的提示词；未开启看图描述时显示原因。
   - **画面参考（还原感觉）**：每个任务把自己的参考图填进图生图输入；仅在所选图片类型的模板声明了 `reference` 槽位且可运行（模型齐全）时可选，否则置灰并说明（“这个图片类型暂不支持画面参考”或“需管理员安装图生图模型”）。
   - 两者可同时勾选（构图描述并入提示词 + 参考图进图生图输入）。
3. **数量提示**：有参考图时，出图按钮的数量提示改为“商品数 × 参考张数 × 候选张数”，实时更新；超过 20 张总上限时禁用并说明（F55）。
4. **一键出整套**：有参考图时，套图按“每张参考一张”展开（用当前所选图片类型的模板），不再按套图类型展开；**分镜（F25）与参考图互斥**，同时使用时提示二选一。
5. **任务卡片**：按参考展开的任务在卡片上显示**对应参考图的缩略图**，并可展开查看该任务实际使用的提示词（沿用 F56 的 `prompt_used`）。
6. **版权提示**：上传入口下方固定提示——参考图只用于借鉴构图与光线，请使用有权使用的图片（自己拍摄、已授权或无版权限制）；生成结果请勿与参考图雷同。
7. **海外平台加强提示**：所选平台的 `region` 为 `global` 时追加提示——海外平台对图片相似度审核更严格，建议只借鉴构图，上架前自行确认不与参考图雷同。

## 5. 数据与接口

| 接口 | 改动 |
|---|---|
| `EcomCraftStudioGenerate` | 新增可选 `reference_images`（图片 data URL 数组，1–8 张）与 `reference_mode`（`composition` / `scene`，多选数组）：多张时服务端展开为多个任务（每个参考一个），提示词组合在后台按任务进行（F56 流程），响应沿用批次/任务结构 |
| `EcomCraftStudioGenerateSet` | 同上参数；有参考图时批次按 商品 × 参考 展开（每个参考一个任务，模板用当前选择），与 `shots` 互斥（同时提交返回 `invalid_parameters`）；任务带 `reference_index` 供前端显示参考缩略图 |
| `EcomCraftStudioExpandPrompt` | 不改：AI 扩写仍只处理描述与产品类型；参考图的构图描述在提交后由后台逐任务生成，任务卡片可查看实际提示词 |
| `EcomCraftStudioTemplates` | 模板条目新增 `reference_slot`（是否声明画面参考槽位），前端据此控制路径二可用性 |
| 校验 | `reference_images` 每项为图片 data URL，服务端与商品图相同的方式校验大小与格式，数量 1–8；`reference_mode` 白名单枚举；模板校验 `reference.image` 须为快照图片参数且不与 `brand_kit` 槽位重复 |

## 6. 版权与合规边界

- **不做**：竞品图自动抓取、竞品图库或推荐、任何“一键复刻 / 同款”功能——这是红线。
- 界面固定版权提示 + 海外平台加强提示（第 4 节）。
- 生成结果与参考图的相似度检查（过高时警告）挂在 F21 候选图自动筛选下，本期不做。
- 平台导出（F58）不感知参考图；AI 元数据按现有 F22 规则写入。

## 7. 存储与隐私

- 参考图**只在请求与内存批次中存在**：与商品图同样随批次在内存中保留（批次 6 小时过期），**不写入 `Data/`**，不进商品库（F36）、项目归档（F04）、候选清理登记（F39）、诊断包（F44）和备份（F45）。
- 只对提交者本人可见；队列、进度等共享接口不返回参考图。
- 实现时在 AGENTS.md 补充对应规则（参照 F04 项目归档的做法）。

## 8. 分期与依赖

| 期 | 内容 | 依赖 | 任务 |
|---|---|---|---|
| P1 | 参考图上传（最多 8 张）与版权提示、“参考一张出一张”的任务展开（单次与套图，含与分镜互斥、20 张上限）、借鉴构图（vision 逐任务读图并入提示词，F56 后台流程）、任务卡片参考缩略图、海外平台加强提示 | 无硬依赖（A5 的 vision 开关已有） | T61（M） |
| P2 | 画面参考：模板 `reference` 槽位与校验、每个任务把自己的参考填入图生图输入、图生图模板（N02 / F57 扩展）、依赖检查展示 | **N10**（图生图方案与模型安装）、N02 | T62（L，未开始） |
| P3（预留） | 整套参考 → 整套生成：视觉模型识别每张参考的图片类型（白底 / 场景 / 细节 / 模特）并自动匹配模板，一次生成整套 | P1 落地后的 vision 分类准确率、N10、种子团队反馈 | 未立项，见第 10 节说明 |

## 9. 验收标准（T61）

- 上传 3 张参考图 + 1 个商品：出 3 张图，各自贴合**对应**参考的构图（不是混合感觉）；上传第 9 张被拒并有提示。
- 2 个商品 × 3 张参考 × 2 候选 = 12 张可提交；再增加导致超过 20 张时按钮禁用并说明。
- 分镜与参考图同时使用时提示二选一；有参考图时“一键出整套”按参考展开，预计张数提示正确。
- 任务卡片显示对应参考缩略图和实际提示词；关闭 vision 时界面说明原因、按普通出图不受影响。
- 参考图不出现在商品库、画廊、归档、诊断包中；重启服务后不留任何参考图数据。
- 选海外平台时出现加强提示；国内平台只显示基础版权提示。
- 中英文界面完整；`studio-i18n` 与 `simple-mode` 测试通过。
