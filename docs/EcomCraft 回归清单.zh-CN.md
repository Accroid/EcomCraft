# EcomCraft 回归清单

> **语言：** 简体中文 · [English](EcomCraft%20Regression%20Checklist.md)
>
> **用途：** 《[EcomCraft 重构计划](EcomCraft%20重构计划.zh-CN.md)》的检查点 CP0–CP3 用它确认重构没有改变行为。

## 怎么用

1. 在能跑显卡的电脑上，用同一套模型和数据运行，并打开浏览器开发者工具的控制台。
2. 准备一个管理员账号、一个普通账号、一张透明底商品图、一张普通商品照片和两张参考图。
3. 逐项操作，在“结果”列记录通过、不通过或未测，并写明提交号。
4. **CP0 记基线：** 已知不通过的项保留在表里并注明现象。之后的检查点只判断有没有变差。

本清单描述当前版本的界面。单入口改版（T89、T90）完成后，第 3–5 项要同步改写。
