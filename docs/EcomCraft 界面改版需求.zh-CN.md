## 1. 背景

目标用户分三类（架构文档 A2）：运营人员和小店老板用简易模式快速出图，平面设计人员用专业模式做更丰富的效果图，管理员负责安装和配置。按账号数收费，不做复杂角色与权限（A12）。

简易模式改版 v3 之后，第 2 步堆了十几项控件（平台、参考图、图片类型、产品类型、风格、模特、品牌资料包、一句话描述、AI 扩写、双语提示词、张数、一键出整套、卖点分镜），已经不“简易”。运营和老板最常做的是**照着竞品参考图做**，但参考图入口夹在中间。本次改版把简易模式、专业模式、画廊、队列和管理界面一起整理。

## 2. 已确认的决策

| 编号 | 决策 |
|---|---|
| U1 | 范围：简易模式、专业模式、画廊、队列、管理界面一起改；按第 7 节任务逐个开发，直接改代码，不另做原型。 |
| U2 | 视觉方向保留：中性灰“摄影棚”风格（界面设计文档第 2 节），只调排版和信息层级。 |
| U3 | 简易模式“先选任务，再填内容”：顶部三个任务入口，**照参考图做**（排第一，默认）、**做一张图**、**出一整套**；每个任务只显示它需要的选项。 |
| U4 | 视觉风格、需要模特、品牌资料包、一句话描述与 AI 扩写、双语提示词默认收进“更多选项”，展开状态记在浏览器；卖点分析与分镜只在“出一整套”里出现。 |
| U5 | 出图后可以对候选图点“收藏”（与画廊的收藏是同一件事），用于初步筛掉效果不好的图。基于收藏的个性化分析和提示词反哺先记为待办（F67，第 6 节草案），以后再开发。 |
| U6 | 设计师（任何账号）可以在专业模式里上传 ComfyUI 工作流 JSON，**上传后自己马上能用**（“我的工作流”，只对上传者可见）；管理员审核发布后，其他账号才能用。自用工作流同样经过服务端结构校验并自动生成参数白名单，只在已登记的执行服务器上执行，拒绝管理员禁用的节点类型（默认禁用能执行任意代码或读写任意路径的节点）；出图请求仍只提交工作流 ID 和白名单参数。（2026-10-29 修订：原为“发布后才能用”） |
| U7 | 简易模式到专业模式单向衔接：候选图上“在专业模式里精修”，把这张图和实际发送的英文提示词带到专业模式；专业模式不回写简易模式。 |
| U8 | “原生引擎”入口只给管理员看。 |
| U9 | 手机只做简易模式（以及画廊查看和队列）；窄屏不显示专业模式入口，打开专业模式时提示到电脑上操作。 |
| U10 | 用词统一（第 3 节）。 |
| U11 | 管理功能收进顶栏右侧的“管理”菜单，只有管理员看得到（第 4 节）。 |
| U12 | 看图描述默认开启（用于参考图借鉴构图），管理员可在提示词优化设置中关闭。没有可用的视觉模型时，页面说明缺什么并给出处理步骤：管理员看到具体操作（运行一键安装脚本，或安装 Ollama 并拉取视觉模型，或在提示词优化设置中改用其他视觉服务），普通账号看到“请联系管理员”。把商品图发给视觉模型自动描述商品仍默认关闭（A5）。 |

## 3. 用词

| 统一说法 | 不再使用 | 说明 |
|---|---|---|
| 出图 | 创作、生成图片（简易模式内） | 简易模式的导航和按钮 |
| 专业模式 | 创作视图、标准工作台 | 设计人员的视图 |
| 图片类型 | 模板（对运营） | “模板”只出现在管理界面 |
| 工作流 | — | 只出现在专业模式和管理界面 |
| 参考图 | 竞品图、样图 | 照着做的图 |
| 收藏 | 喜欢、星标 | 候选图和画廊共用 |
| 执行服务器 | 后端、显卡电脑 | 管理和队列里 |

## 4. 导航与管理入口

- 顶栏导航：**出图**、**专业模式**（所有账号，窄屏隐藏）、**画廊**、**队列**。
- 顶栏右侧：服务器状态、语言、主题、账号名；管理员另有“管理”菜单：工作流审核、首次设置向导、提示词优化设置、存储与备份、原生引擎（新标签页）。
- 工作流上传在专业模式里（U6），上传者马上能用；面向全员的审核发布在“管理”菜单里。

## 5. 简易模式

页面顶部是三个任务卡片，选中的任务记在浏览器，首次打开默认“照参考图做”。三个任务共用第 1 步（上传商品图）和第 3 步（挑图下载）；第 2 步按任务显示：

| 第 2 步内容 | 照参考图做 | 做一张图 | 出一整套 |
|---|---|---|---|
| 平台 | 显示 | 显示 | 显示（含可选槽位） |
| 参考图与逐张提示词 | 显示（必填，1–8 张） | — | — |
| 图片类型 | — | 显示 | —（按平台套图） |
| 产品类型 | — | 显示 | 显示 |
| 更多选项（风格、模特、品牌资料包、一句话描述与 AI 扩写、提示词） | — | 收起 | 收起 |
| 候选张数 | —（每张参考出 1 张） | 显示 | 显示 |
| 卖点分析与分镜 | — | — | 显示（折叠） |
| 主按钮 | 按参考出图 | 开始出图 | 一键出整套 / 按分镜出整套 |

- 切换任务不清空已上传的商品图和参考图；参考图只在“照参考图做”里生效。
- 第 3 步：候选图可以收藏（U5）、下载、导出到平台、做成卖点图、在专业模式里精修（U7）。

## 5.1 自用工作流（F60，T63）

- 入口在专业模式的工作流下拉框下方：“上传工作流”选择 ComfyUI 菜单“保存”（Save）得到的 `.json`，名称取文件名；下方列出“我的工作流”，显示能在几台执行服务器上运行或缺少哪些节点、模型，可删除。下拉框里自用工作流单独成组“我的工作流”。
- 只接受“保存”格式；“导出（API）”格式提示改用“保存”。结构不受支持、超过 2 MB、每个账号超过 20 个时拒绝并说明原因。
- 禁用规则（三层）：节点类型名按单词拆分后含 `python`、`exec`、`execute`、`eval`、`script`、`shell`、`command`、`cmd`、`code`、`subprocess` 的拒绝；文本参数像文件路径（盘符、网络共享、以 `/` 开头的绝对路径或含 `..`）的拒绝；管理员可在服务器设置 `EcomCraft.DeniedWorkflowNodes` 追加节点类型名。拒绝时列出节点和参数名。
- 自用工作流只对上传者可见：目录、出图、参数提供与执行服务器校验都核对所有者；它不出现在审核列表，审核接口也拒绝处理它，模板不能引用它。工作流 JSON 只存在服务端，不返回给客户端。
- 提交审核与发布（T73）：“我的工作流”里未提交或被驳回的可以“提交审核”（可写一句说明）；管理员在“管理 → 工作流审核”中看到来源为“账号上传”的待审核项，像其他工作流一样配置参数、通过或驳回。通过后复制为 `上传/<名称>` 的正式发布快照，所有账号可用，下架作用于这份副本；上传者的自用原件保留。驳回原因只给上传者看，修改后重新上传再提交。

## 6. 收藏与个性化分析（F67，待办草案）

本节只是方向草案，开发前需再确认，并先在 AGENTS.md 补充数据保存规则。

1. **收藏即初筛（F65，本次开发）**：候选图上的收藏按钮复用画廊收藏，收藏的图不会被候选图自动清理。
2. **偏好统计（第一阶段）**：按账号统计收藏率最高的图片类型、产品类型、视觉风格、是否用模特、平台，只保存这些选项 ID 和计数，不保存图片和提示词；用于把常收藏的选项排在前面或预选。
3. **提示词反哺（第二阶段）**：对比收藏与未收藏作品的提示词，找出收藏作品里更常出现的描述片段（如光线、背景、构图词），作为“你可能喜欢的描述”建议给用户，用户确认后才加入一句话描述或品牌资料包；从不在后台自动改提示词。因为要读取提示词，这一阶段的记录规则参照项目归档（只给本人、可删除、写入经临时文件替换）。
4. **模型层面（远期）**：用收藏作品训练品牌专属 LoRA 归入 F17（定制服务），不在本需求内。
