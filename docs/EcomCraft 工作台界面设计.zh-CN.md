| 项 | 内容 |
|---|---|

## 2. 设计方案

### 2.1 核心思路

**界面要像摄影棚的灰卡一样中性。** 商品图最怕偏色判断，界面本身不应该带强烈的色相去干扰对商品颜色的判断。所以界面主体用中性灰，颜色只留给“操作”和“状态”两类信息。

唯一的视觉重点放在**预览区“无缝背景纸”**上：预览区做成摄影棚的弧形背景纸（上墙下地、中间一道柔和的弯），生成结果像商品一样放在背景纸上展示。空状态用取景框的四角标记，而不是通用的虚线框加号。生成中，背景纸角落亮一盏红色“拍摄指示灯”，配合已等待的秒数，这是整个页面唯一的自动动画。

其余部分保持安静：不做每张卡片的悬停上浮，不做每个区块的淡入，不用渐变装饰。

### 2.2 颜色

| 名称 | 浅色（灰卡） | 深色（暗房） | 用途 |
|---|---|---|---|
| 背景纸 | `#E8E8E6` | `#1E1F20` | 页面底色、预览区背景纸 |
| 面板 | `#F7F7F5` | `#28292A` | 表单、列表、弹窗 |
| 墨色 | `#1F2123` | `#ECECEA` | 正文、标题 |
| 18% 灰 | `#616365` | `#9A9C9E` | 次要文字、说明（在面板和背景纸上均不低于 4.5:1） |
| 绿幕 | `#0B7A53` | `#3FBF8A` | 主要操作、选中状态、焦点环 |
| 指示灯 | `#D93A26` | `#FF6A55` | 生成中、繁忙、删除等需要注意的状态 |
| 琥珀 | `#D97706` | `#FBBF24` | 服务器“忙碌”（有任务在执行但未排队）的指示灯 |

- 对比度（WCAG AA 要求 4.5:1）：浅色主题白字压在绿幕色上约 5.3:1、压在指示灯色上约 4.6:1；深色主题按钮使用深色字，压在绿幕色上约 7.1:1；18% 灰在浅色面板上约 5.6:1、背景纸上约 4.9:1，在深色面板上约 5.3:1。
- 线框和分隔线由墨色按透明度派生，不另设颜色。
- 不使用阴影堆叠层级；层级靠面板与背景纸的明度差和 1px 分隔线表达。只有弹窗和大图预览使用一层阴影。

### 2.3 字体

工作台的内容安全策略只允许加载本站资源，不能使用在线字体，因此使用系统字体：

| 角色 | 字体栈 | 用法 |
|---|---|---|
| 标题 | `"Noto Serif SC", "Source Han Serif SC", "Songti SC", "STSong", "SimSun", serif` | 页面标题、空状态标题，24px 以上；像商品画册的标题 |
| 正文与控件 | `"PingFang SC", "Microsoft YaHei UI", "Microsoft YaHei", "Noto Sans SC", system-ui, sans-serif` | 其余所有文字 |

- 字号阶梯：12 / 13 / 14 / 16 / 20 / 28 px，正文 14px，行高 1.6；说明文字 12px。
- 数字（尺寸、张数、秒数、排队数）使用 `font-variant-numeric: tabular-nums`，不用等宽字体。
- 不使用全大写标签、字间距拉开的小标签、单词局部变色。

- 左侧深色侧栏改为顶栏导航：三个视图只有三个入口，侧栏占掉 232px 却只放了三个链接；顶栏把宽度还给预览区。
- 表单列固定宽度、左对齐，内部只用分隔线分组，不再把每个字段做成卡片。
- 窄屏（< 1100px）：表单与预览上下排列，预览在上，方便先看结果。
- 手机端暂不专门适配，只保证页面在窄屏下不错位、不出现横向滚动。

```
┌────────────────────────────────────────────────────────────────────┐
│ 作品画廊                                                12 个作品  │
│ [全部 | 已收藏]  [搜索文件名…]  [最新优先 ▾]  [刷新]  [选择]       │
├────────────────────────────────────────────────────────────────────┤
│ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐                       │
│ │      │ │      │ │      │ │ ▶视频 │ │      │   方形取景，不裁切主体 │
│ └──────┘ └──────┘ └──────┘ └──────┘ └──────┘                       │
│ 0312-精华液  ★   0311-运动鞋   …                文件名在图片下方   │
└────────────────────────────────────────────────────────────────────┘
```

- 像摄影师的印样（contact sheet）：缩略图统一方形取景、图片以“完整显示”方式放入（不裁掉商品），文件名在图片下方常驻显示，不再依赖鼠标悬停才能看到。
- 生成时间在文件名下一行单独显示（HH:mm:ss，悬停可见完整日期），按日期分组时每组标题显示日期与数量。
- 收藏星标常驻显示（未收藏为空心），删除按钮在悬停或键盘聚焦时出现；触屏设备常驻。
- 删除已收藏的作品时，同时删除收藏副本（Starred/）和原始文件，画廊“全部”与“收藏”里都不再出现。

- 服务器做成表格（真正的表格数据，用 `<table>`），状态用指示灯颜色 + 文字双重表达，不只靠颜色。

### 2.5 原则

1. **中性优先**：界面不抢商品的颜色；颜色只表达“能点”和“要注意”。
2. **一个重点**：只有预览区背景纸有造型和动画，其余部分克制。
3. **说清楚下一步**：每个空状态、错误、禁用按钮都告诉用户原因和怎么做。
4. **按钮名即结果**：“生成图片”生成后提示“已生成 2 张图片”；“删除所选”完成后提示“已删除 3 个作品”。

### 2.6 对照常见模板的自查

| 初稿 | 问题 | 修改 |
|---|---|---|
| 沿用现在的蓝紫色 `#4f6bff` 作主色 | 通用 SaaS 蓝，与商品摄影无关 | 改为绿幕色，只用于操作和选中 |
| 白色圆角卡片 + 统一柔和阴影 | 第 4 类模板特征 | 取消字段卡片和通用阴影，用分隔线分组 |
| 品牌副标“STUDIO · 商创工坊”用等宽小字、标签 `IMAGE` | 全大写标签、等宽小字、中点拼接 | 删除 `IMAGE` 标签和等宽小字；副标题去掉 |
| 生成按钮带 `→` 箭头、“下载原文件 ↓” | 第 5 类模板特征 | 去掉箭头，按钮文字说明结果 |
| 首页口号“让商品，有新的表达” | 营销口号，不帮助操作 | 改为当前任务说明，例如“生成商品图片” |
| 页脚“基于 SwarmUI 二次开发 · 为电商团队创作” | 中点拼接，无信息 | 页脚只保留版本号与原生引擎入口 |

| 取消 / 保存 | 关闭或保存 | 正常；**Esc 无法关闭** | 保留；支持 Esc；保存中显示“保存中…” |

### 3.9 通用要求（全部页面）

- 所有可点击元素使用 `<button>` 或 `<a>`；图标按钮带 `aria-label`；装饰图标 `aria-hidden="true"`。
- 键盘：所有操作可用 Tab / 回车 / 空格完成；焦点环使用绿幕色，清晰可见。
- 弹窗：打开时焦点移入，Tab 在弹窗内循环，关闭后焦点回到触发按钮；弹窗内滚动不带动页面（`overscroll-behavior: contain`）。
- 动画：只用 `transform` / `opacity`；不使用 `transition: all`；尊重“减少动态效果”系统设置。
- 文案：加载状态以“…”结尾；错误说明原因和下一步；按钮写结果而不是“确定”。
- 深色主题：`color-scheme` 跟随主题，下拉框显式设置背景色与文字色（Windows 深色模式）。
- 不禁止页面缩放；按钮点击区域不小于 32px。

## 5. 实现与验收说明

### 5.1 与检查清单的差异（有意保留或暂未实现）

| 规则 | 现状 | 原因 |
|---|---|---|
| 提交按钮在请求开始前保持可用 | 生成按钮在条件不满足时禁用，下方写明原因 | 生成会占用 GPU，避免无效提交；原因始终可见 |
| 拖拽类手势需要点击 / 键盘替代 | 局部重绘的蒙版需要涂抹 | 绘制蒙版本身就是该功能，不可替代 |
| 图片需要明确宽高 | 生成结果和大图预览的图片未写固定宽高 | 尺寸由生成参数决定，容器已固定高度，不会造成布局跳动 |
| 筛选状态写入地址 | 视图（创作 / 画廊 / 队列）已写入地址；画廊的筛选和搜索未写入 | 本期范围外，后续需要时补充 |
| 手机端适配 | 只保证窄屏不错位 | 按确认结果暂不考虑手机操作；拍照上传（F42）和画廊窄屏单列（≤560px）已实现 |

### 5.3 同时修复的现有缺陷

1. 手机菜单按钮点击报错（`$('.rail')` 取不到元素）——随侧栏一起移除。
2. 主题按钮同时显示太阳和月亮图标。
3. 生成结果显示为可放大但点击无反应。
4. 画廊视频用图片标签显示，缩略图是坏图。
5. 画廊卡片、星标无法用键盘操作；扩图方向按钮被 `aria-hidden` 隐藏。
6. 大图预览的图标按钮缺少无障碍名称；提示词设置弹窗无法用 Esc 关闭；弹窗打开后焦点不进入弹窗。
7. 上传区键盘聚焦时看不到焦点。
8. LoRA 的移除按钮缺少 `type="button"`，点击移除会同时提交表单、触发一次生成。
9. “刷新工作流”与“刷新模型”两个按钮功能重复。
10. 队列更新时间按浏览器语言显示（例如韩文系统显示“오후”），现固定为中文格式。
11. 页脚版本号写死，现由服务端返回扩展版本。
