# EcomCraft M0 Diagnostics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 提供不出网、不生成、权限受控且不会伪报就绪的管理员节点诊断。

**Architecture:** 独立 SwarmUI 扩展将宿主状态投影为白名单观测模型，由纯判定器生成检查结果。管理员通过一个只读 API 和现有主题内的标签查看快照、下载报告；不向原生生成链路注册钩子。

**Tech Stack:** C# 12 / .NET 8、SwarmUI 扩展 API、Newtonsoft.Json、原生 JavaScript、Node 内置测试，无新增第三方包。

## Global Constraints

- 全部改动限定 `src/Extensions/EcomCraft/`；不改核心、根目录忽略规则、远端或现有数据。
- 不执行构建、GPU 测试或启动生产服务；当前本机没有 dotnet。
- 不进行任何扩展主动网络连接；不自动修改认证、后端和更新配置。
- 权限 `view_extension_tab_ecomcraft` 默认 ADMINS，API 和标签共用；请求内再次核验。
- 总结状态只能 blocked / pending_verification，不把快照当作心跳或实测证据。
- 不引入 UI 框架、外部字体、CDN 或新 NuGet 包。
- 不自动提交或推送；工作留在 feature/ecomcraft-m0-diagnostics，供用户审阅。
