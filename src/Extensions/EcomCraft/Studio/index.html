                      作品存储
                      
                    
                      作品总是先保存在平台服务器本机，再在后台复制到作品库；作品库离线不影响生成。
                      
                
                      
                
            
                      
            
                      
                
                      
                    
                    
                    
                      本机目录、\\服务器\共享 形式的网络路径，或 Linux / macOS 上已挂载的目录。不支持映射的网络盘符。能访问这个位置的人可以看到所有人的作品。
                      
                
                      
                
                      
                    
                    
                
                      
                
                      
                    
                    
                    
                      简易模式里没被选中、下载或导出的候选图，超过这个天数后自动清理；填 0 表示不清理。选中、下载或导出过的永久保留。
                      
                
                      
                
                      
                    
                    
                    
                    
                    
                      后台定期检查平台服务器和作品库的剩余空间：低于警告阈值时管理员可见提醒，低于严重不足阈值时拒绝新的生成。填 0 表示不启用。
                      
                
                      
                
                      
                    系统数据备份与恢复
                    
                      备份包含模板、审核快照、存储设置和账号数据库，不包含作品文件。恢复会覆盖当前系统数据，完成后需重启服务；被占用的账号数据库文件会放入暂存目录，按升级说明在停机后替换。
