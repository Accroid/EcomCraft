            配置 ComfyUI 执行服务器，以及可选的云端提示词模型。

            1. 配置 ComfyUI 执行服务器已完成

              • 安装时系统会自动扫描常见目录，发现 ComfyUI 后自动写入本机自启动后端参数。
              • 首次启动时系统还会自动生成模型路径配置，把工作台模型目录和内置节点目录接入 ComfyUI。
              • 没有自动识别时，打开原生引擎的 Server / Backends，在页面顶部点击“Scan ComfyUI”。
              • 找到多个安装位置时，选择要使用的路径和后端，再点击该后端卡片上的 Save。
              • 局域网内其他装有 ComfyUI 的设备：以 --listen 启动 ComfyUI，再在 Server / Backends 添加“ComfyUI API By URL”后端，填写局域网地址并设置显示名称。
              打开原生引擎的后端设置

            2. 配置云端提示词模型（可选）已完成

              • 在本页点击“优化提示词”旁的“设置”，选择 OpenAI、Claude、OpenRouter 或 Grok。
              • 填写服务商 API Key；Key 只保存在服务端，不会显示在工作台。
              • 填写模型 ID 并保存，可以先点击“拉取”验证服务地址和权限。

            图片和视频只在已登记的本机或局域网 ComfyUI 执行服务器上生成，不会自动切换到云端。
